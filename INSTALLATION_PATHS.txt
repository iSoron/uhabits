  Default Location: C:\Users\w11-d\AppData\Local\Android\Sdk

  Within SDK, you need:
    ├── platforms/
    │   ├── android-36/        (REQUIRED - API 36)
    │   └── android-28/        (REQUIRED - API 28)
    ├── build-tools/
    │   └── 36.0.0/            (REQUIRED)
    ├── platform-tools/        (REQUIRED)
    │   ├── adb.exe
    │   └── fastboot.exe
    └── cmdline-tools/         (For CLI installation)
        └── latest/

  Installation Method A - Android Studio (Easiest):
    1. Download: https://developer.android.com/studio
    2. Run installer
    3. Studio auto-downloads SDK during setup
    4. Note SDK location from IDE
    
  Installation Method B - Command Line:
    1. Download cmdline-tools from: https://developer.android.com/studio#downloads
    2. Extract to: C:\Users\w11-d\AppData\Local\Android\Sdk\cmdline-tools\latest
    3. Run: sdkmanager --licenses
    4. Run: sdkmanager "platforms;android-36"
    5. Run: sdkmanager "platforms;android-28"
    6. Run: sdkmanager "build-tools;36.0.0"
